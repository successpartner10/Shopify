    How it works

    1. Open Shopify — have admin open in a browser tab.
    2. Tap Start scan — pick that Shopify tab in the share picker. On phones that cannot share tabs, upload an OS screenshot (not a camera photo).
    3. Tap What's wrong? — we read on-screen text, search the local playbook, and only then consider a broader fallback. Arrows point at the control to use next.

    Nothing is stored as an image unless you keep the file yourself. Session history saves the tip text only.

    Privacy

    Shopify admin can show customer names, payouts, and API keys. Treat this tool like a person looking over your shoulder.

    • Screen pixels are processed in your browser. We do not upload screenshots to a Storescope server.
    • OCR libraries may load from a public CDN the first time you scan.
    • History stores tip text in IndexedDB on this device — never the raw image.
    • Use Pause before opening customer lists or secret keys.
    • The browser share dialog is the only way we can see a tab. You can stop sharing at any time.
